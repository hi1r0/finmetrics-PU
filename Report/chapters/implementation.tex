\section{Technologies Used}
The \textit{FinMetrics Suite} is developed entirely in Python 3.10+, utilizing standard scientific computing, data science, and machine learning libraries.

\section{Tools and Libraries}
The package dependencies and their structural roles are defined below:
\begin{itemize}
    \item \textbf{Pandas (v2.1.1)}: Used for high-speed tabular operations and statement transpositions.
    \item \textbf{NumPy (v1.26.0)}: Provides vector operations, array manipulation, and robust calculations to avoid zero-division errors.
    \item \textbf{SciPy (v1.11.3)}: Supplies scientific functions, specifically `scipy.stats.percentileofscore` for ranking companies.
    \item \textbf{Scikit-Learn (v1.3.1)}: Powers the machine learning engines: RobustScaler for median-based scaling and IsolationForest for multi-dimensional anomaly detection.
    \item \textbf{Streamlit (v1.27.2)}: Provides the web frontend framework, handling interactive dashboards, stateful re-runs, and file upload structures.
    \item \textbf{Plotly (v5.17.0)}: Generates interactive visualizations (scatter plots, rank bar charts, heatmaps).
    \item \textbf{yfinance (v0.2.31)}: Handles connections to the Yahoo Finance API to fetch statements and market metrics.
    \item \textbf{openpyxl \& XlsxWriter (v3.1.2)}: Generates styled multi-sheet Excel reports.
    \item \textbf{google-generativeai (v0.3.1)}: Manages Gemini model integration for natural-language stock discovery and diagnostic chats.
\end{itemize}

\section{Module-wise Implementation Details}
The key modules are implemented as isolated classes:

\subsection{Financial Standardizer (financial\_parser.py)}
The standardizer uses a nested dictionary structure containing alias mappings for each statement. It scans the rows, maps variants using the alias list, removes duplicate metrics, and converts all entries to numeric types:
\begin{lstlisting}[language=python, caption=Alias Resolver in FinancialParser]
def _resolve_alias(self, raw_name: str, alias_dict: dict) -> str:
    norm = raw_name.strip().lower()
    for canonical, variants in alias_dict.items():
        for v in variants:
            if v.lower() == norm:
                return canonical
    return None
\end{lstlisting}

\subsection{Outlier Scoring (outlier\_engine.py)}
Calculates severity scores and directional flags. It computes IQR fences and robust standard deviations to flag statistical anomalies:
\begin{lstlisting}[language=python, caption=Severity Score Formulation]
def _severity(self, val: float, lower: float, upper: float, iqr: float, z: float) -> float:
    iqr_score = 0.0
    if iqr > 0:
        if val < lower:
            iqr_score = (lower - val) / iqr
        elif val > upper:
            iqr_score = (val - upper) / iqr
    z_score = max(0.0, abs(z) - self.zscore_threshold)
    return round(0.6 * iqr_score + 0.4 * z_score, 3)
\end{lstlisting}

\section{System Component Integration}
The platform's analytical capabilities are integrated through an end-to-end orchestration pipeline controlled by the Streamlit application framework (\texttt{app.py}). Serving as the central controller, \texttt{app.py} manages user session state, coordinates parameter calibration, and dispatches tasks sequentially across the analytical modules:
\begin{enumerate}
    \item \textbf{Data Harvester (\texttt{DataFetcher})}: Fetches multi-year quarterly and annual financial statements alongside market capitalization data via the Yahoo Finance API, persisting raw dataframes in Parquet format with a 24-hour time-to-live (TTL) cache.
    \item \textbf{Canonical Standardizer (\texttt{FinancialParser})}: Normalizes disparate accounting nomenclature into canonical financial fields using a 60-field synonym dictionary, enforcing cross-statement data consistency.
    \item \textbf{Mathematical Kernel (\texttt{RatioEngine})}: Computes 30+ financial ratios across five core performance pillars (Profitability, Operating Efficiency, Solvency, Liquidity, and Cash Flow Health) and reconstructs historical quarterly time-series and YoY growth trajectories.
    \item \textbf{Anomaly Engine (\texttt{OutlierEngine})}: Applies multi-tier statistical outlier filters---Tukey Interquartile Range (IQR) fences, MAD-based modified Z-scores, and multivariate Isolation Forest estimators---to flag abnormal values.
    \item \textbf{Scoring \& Ranking Kernel (\texttt{BenchmarkCore})}: Masks identified statistical anomalies, computes clean peer distribution baselines (medians, quartiles), and applies median-centered robust scaling and sigmoid scoring to derive composite health scores and percentile ranks.
\end{enumerate}

Following completion of the analytical pipeline, the evaluated outputs are published to the presentation layer as interactive Plotly heatmaps, radar profiles, company ratio scorecards, and downloadable multi-sheet styled Excel workbooks generated via \texttt{ReportGenerator}.
