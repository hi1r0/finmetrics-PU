\section{System Architecture}
The \textit{FinMetrics Suite} is structured as a decoupled, multi-layer architecture. This decoupling ensures that the user interface (UI) layer is separated from the analytical modules, database cache, and API engines, facilitating code maintenance and extensions.

The architecture is divided into three primary layers:
\begin{enumerate}
    \item \textbf{Presentation Layer (Streamlit UI)}: Renders the sidebar controls (sector/scope selection, threshold calibrations), interactive analytical tabs, Plotly charts, and styled report export facilities.
    \item \textbf{Analytical Kernel Layer (Python Packages)}: The core processing layer containing standard modules:
        \begin{itemize}
            \item \textbf{Sector Loader}: Maps sectors to public tickers.
            \item \textbf{Data Fetcher}: Retrieves Yahoo Finance statements and manages local cache.
            \item \textbf{Financial Parser}: Standardizes columns using the alias dictionary.
            \item \textbf{Ratio Engine}: Computes 30+ ratios and YoY growth rates across 5 core pillars.
            \item \textbf{Outlier Engine}: Identifies anomalies using multi-tier statistical filters (IQR, MAD Z-score, Isolation Forest).
            \item \textbf{Benchmark Core}: Coordinates baseline calculation, cell-level outlier masking, and robust peer statistics.
            \item \textbf{Benchmark Classifier}: Assigns health labels, signal classes, and percentile rankings.
            \item \textbf{Benchmark Store}: Persists and retrieves precomputed sector benchmark matrices in Parquet format.
            \item \textbf{AI Handler}: Manages Gemini ticker discovery and diagnostic commentary.
            \item \textbf{Report Generator}: Compiles multi-sheet styled Excel workbooks and analytical outputs.
        \end{itemize}
    \item \textbf{Data Cache Layer}: Persistent storage in JSON and Parquet formats to avoid API rate limits.
\end{enumerate}

\section{System Workflow and Execution Pipeline}
The application executes in a clean, stateful single-track process flow comprising ten sequential execution stages:

\begin{enumerate}
    \item \textbf{Scope Definition}: The user defines the benchmark scope via the sidebar by selecting a pre-mapped Sector, choosing a granular Industry, or inputting an abstract search prompt for Gemini AI Search.
    \item \textbf{Environment Check \& API Key Configuration}: The sidebar inspects environment variables and user configuration to verify active Google Gemini API keys and runtime parameters.
    \item \textbf{AI Ticker Discovery}: If AI Search is selected, the \textit{AI Handler} queries Gemini to discover relevant listed stock tickers dynamically, appending required exchange suffixes (e.g., \texttt{.NS} for the National Stock Exchange of India).
    \item \textbf{Statement Harvesting \& Caching}: The \textit{Data Fetcher} checks local storage for cached statements; if missing or expired, it queries the Yahoo Finance API via \texttt{data\_fetcher.py} and stores normalized statements in a 24-hour Parquet cache.
    \item \textbf{Canonical Synonym Resolution}: The \textit{Financial Parser} (\texttt{financial\_parser.py}) resolves nomenclature variations across accounting reporting formats using a 60-field canonical alias map (\texttt{ALIAS\_MAP}), standardizing statements into uniform DataFrames.
    \item \textbf{Ratio Calculation}: The \textit{Ratio Engine} (\texttt{ratio\_engine.py}) computes over 30 standardized financial ratios and YoY growth metrics organized across 5 core pillars: Liquidity, Solvency, Profitability, Efficiency, and Valuation.
    \item \textbf{Multi-Tier Outlier Detection}: The \textit{Outlier Engine} (\texttt{outlier\_engine.py}) executes statistical anomaly screening across all ratios using an ensemble of Interquartile Range (IQR) fences, MAD-based modified Z-scores, and multivariate Isolation Forests.
    \item \textbf{Outlier Masking and Baseline Generation}: The \textit{Benchmark Core} (\texttt{benchmark\_}\allowbreak\texttt{core.py}) applies cell-level masking to flagged statistical anomalies and computes robust peer statistics (medians, interquartile spreads, and deciles).
    \item \textbf{Scoring, Aggregation and Ranking}: The \textit{Benchmark Classifier} (\texttt{benchmark\_}\allowbreak\texttt{classifier.py}) applies non-linear sigmoid transformations to convert metric deviations into bounded scores (0--100), computes weighted pillar aggregations, and determines final percentile rankings.
    \item \textbf{Output Generation}: The system renders interactive Streamlit tabs, generates styled multi-sheet Excel workbooks via \texttt{report\_generator.py}, and triggers Gemini-powered diagnostic commentary.
\end{enumerate}

\section{Module Descriptions}
The system consists of the following modules, each encapsulating specific functional logic:
\begin{itemize}
    \item \textbf{sector\_loader.py}: A template mapping utility that lists standard public market tickers under 13 sectors: Automobiles, IT, FMCG, Banking, Pharma, Oil \& Gas, Metals, Cement, Telecom, Power, Realty, Capital Goods, and Infrastructure.
    \item \textbf{data\_fetcher.py}: Handles secure connections to the `yfinance` Ticker wrapper. Implements asynchronous API requests and caches raw quarterly/annual statements in Parquet format with a 24-hour TTL config.
    \item \textbf{financial\_parser.py}: Normalizes messy statements into clean, structured DataFrames. Scans the rows, renames matched variants using the alias map \texttt{ALIAS\_MAP}, removes duplicate metrics, and converts all entries to numeric types.
    \item \textbf{ratio\_engine.py}: Performs financial ratio computations. Reconstructs quarterly time-series, calculates YoY/QoQ percentage changes, and computes CAGR growth trends across 5 core pillars.
    \item \textbf{outlier\_engine.py}: The statistical processing module. Implements multi-tier outlier detection via IQR fences, MAD-based modified Z-scores, and multivariate Isolation Forest.
    \item \textbf{benchmark\_core.py}: Orchestrates the baseline calculation. Masks outlier cells, computes clean peer statistics (medians, deciles), and ranks firms by their weighted composite health score.
    \item \textbf{benchmark\_classifier.py}: The business logic translator. Assigns health labels, signal classes, and percentile ranks based on metric performance against sector distributions.
    \item \textbf{benchmark\_store.py}: Persists and retrieves precomputed sector benchmark matrices in Parquet format.
    \item \textbf{report\_generator.py}: Generates styled Excel workbooks using custom colors, column auto-fitting, and formatted dashboards.
    \item \textbf{ai\_handler.py}: Integrates with the Gemini API to search for sector tickers and run the interactive diagnostic chat.
    \item \textbf{visualization.py}: Renders interactive charts (radar profiles, distributions, stacked contribution bars, heatmaps) in Plotly and Seaborn.
\end{itemize}
